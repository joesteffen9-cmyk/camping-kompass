Dazu gehören beispielsweise IP-Adresse, Datum und Uhrzeit des Zugriffs, angeforderte Datei, Browserinformationen und Referrer-Daten. Solche Daten können in Server-Protokollen gespeichert werden, etwa zur Bereitstellung, Stabilität und Sicherheit der Website.

Der konkrete Hosting-Anbieter, seine Speicherfristen und seine Datenschutzinformationen müssen vor Veröffentlichung ergänzt bzw. geprüft werden.

4. Externe Dienste und Inhalte

Die Website lädt nach dem derzeitigen Code externe Inhalte und Bibliotheken. Beim Laden kann eine Verbindung zu den jeweiligen Anbietern hergestellt werden. Dabei können technische Daten, einschliesslich der IP-Adresse, übermittelt werden.

Unsplash

Das Titelbild wird von Unsplash geladen. Beim Abruf des Bildes wird eine Verbindung zu Servern des Anbieters hergestellt. Datenschutzhinweise von Unsplash .

unpkg und Leaflet

Die Bibliothek Leaflet wird über unpkg.com geladen, um die interaktive Karte darzustellen. unpkg · Leaflet.

Für die Karte werden Kartenkacheln von OpenStreetMap geladen. Dabei werden technische Verbindungsdaten an die entsprechenden Server übertragen. Datenschutzhinweise der OpenStreetMap Foundation .

Instagram

Die Website kann Instagram-Reels über ein externes Skript und eingebettete Inhalte anzeigen. Beim Laden dieser Inhalte kann eine Verbindung zu Meta-/Instagram-Servern entstehen. Dabei können technische Daten verarbeitet werden. Datenschutzerklärung von Instagram .

Bitte prüfe, ob Instagram-Inhalte erst nach einer ausdrücklichen Einwilligung geladen werden sollten. Dieser Text ersetzt keine technische Einwilligungslösung.

Google-Favicon-Dienst

Die Symbole der Camping-Shops werden über den Google-Favicon-Dienst geladen. Dabei wird eine Anfrage an Google-Server gestellt. Datenschutzhinweise von Google .
